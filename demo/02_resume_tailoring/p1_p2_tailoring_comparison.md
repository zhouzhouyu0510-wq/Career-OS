# P1 / P2定制对比（Tailoring Comparison）

同一Source of Truth不会生成一份“万能简历”。Resume Tailor根据岗位目标改变Evidence Priority、排序与Safe Translation，但不改变事实、Ownership或Result Scope。

输出入口：[P1 Strategy Submission](strategy_submission_draft.md)｜[P2 Risk Submission](risk_submission_draft.md)

## 同一Evidence的不同处理

| Evidence | P1 Strategy Priority / Translation | P2 Risk Priority / Translation | 不可跨越的Boundary |
|---|---|---|---|
| SYN-EV-ALPHA-01 | High｜产业研究与书面综合 | Medium-Low｜来源可追溯的研究记录 | 不升级为Enterprise Strategy Ownership |
| SYN-EV-ALPHA-02 | High｜市场比较框架 | Omit｜与P2核心职责距离较远 | 分组口径由Project Lead确认 |
| SYN-EV-ALPHA-03 | High｜假设与不确定性梳理 | Medium｜待核验问题识别 | 不包装为Formal Risk Assessment |
| SYN-EV-BETA-01 | Medium｜Data-quality Differentiator | Highest｜数据复核与规则解释支持 | Data Owner拥有规则审批权 |
| SYN-EV-BETA-02 | Medium-Low｜证据回溯能力 | High｜异常分类与来源核验 | 不主张正式风险处置职责 |
| SYN-EV-BETA-03 | Low-Medium｜与Beta-02压缩 | High｜Data-quality Monitoring Support | 不是Risk Control System或监管报告 |

## 输出差异

| Dimension | P1｜Strategy Analyst | P2｜Risk Analyst |
|---|---|---|
| Experience顺序 | Alpha → Gamma → Beta | Beta → Gamma → Alpha |
| 首要Evidence | Industry Research / Comparison / Synthesis | Data Validation / Exception Traceability / QA Monitoring |
| Beta翻译 | 数据质量视角作为差异化补充 | Adjacent Strong的岗位相关Evidence |
| Gamma翻译 | Business Analysis与Decision Support | Transferable Monitoring / Reporting Support |
| Alpha翻译 | Direct Research Evidence | Transferable Evidence Traceability |
| Submission Bullet | 8条 | 8条 |

## Gap差异

- **P1 Gap：**没有Enterprise Strategy Decision Ownership；不能声称制定公司战略或拥有管理层决策结果。
- **P2 Gap：**没有Direct Risk-management Ownership、Risk Model Development或Regulatory Compliance Ownership。
- **共同Technical Boundary：**SQL、Programming、Advanced Statistical Modeling与Production Data Pipeline均缺少Confirmed Evidence，不进入任一Resume。

## 结论

P1与P2使用相同10条Canonical Evidence，但形成不同的Evidence排序、岗位语言与删减方案。差异来自Tailoring，不来自新增Candidate Fact。
