# Career OS V1 — Public Edition Draft

> Stage 01: architecture export and privacy-boundary validation. This is a structural draft, not final launch copy.

Career OS is an evidence-governed workflow for three connected decisions:

1. **Job Fit Analyzer** decides what to apply for.
2. **Resume Tailor** decides how to apply.
3. **Interview Coach** prepares, trains, debriefs, and transfers learning.

This public edition was built through a clean-room whitelist export. It contains only generalized architecture, public schemas, guardrails, and fully synthetic examples. It contains no private candidate assets, real applications, submitted resumes, interview records, evidence files, installation identifiers, or local environment paths.

## Repository map

- `docs/` — architecture, principles, governance, and learning loop.
- `skills/` — non-installable public specifications for the three runtime modules.
- `demo/` — an end-to-end fictional scenario using Candidate A and Company Delta.
- `screenshots/` — reserved for later synthetic screenshots.
- `assets/architecture/` — reserved for later public diagrams.

## Synthetic demo path

`Candidate A → Job Fit → ordered P1/P2 → Resume evidence selection → Interview preparation → Mock/Debrief → Learning Migration`

Every file under `demo/` declares that it is synthetic. Demo content must never be interpreted as a real candidate fact, employer requirement, application decision, or interview record.
