# Experience｜经历记录模板

## AI协作填写｜最简单用法

### 1. 你给AI什么

- 本模板；
- 一段经历在现有简历中的描述；
- 你对该经历的回忆，或有权使用且已经脱敏的项目材料。

一次只处理一段经历。你不需要先填模板。

### 2. 复制这段Prompt

```text
我正在建立Career OS Experience资产。我已提供一段经历的简历描述、回忆或脱敏材料，以及Experience模板。

请先不要写简历Bullet，也不要包装表达。第一轮只输出：
1. 初步事实：背景、任务、个人行动、Deliverable、项目结果和个人贡献；
2. 个人责任边界（Ownership），并区分项目结果与个人结果；
3. 待确认问题。

如果最终决策权无法确认，请向我追问；数字、时间或责任范围无法确认时，标记“待确认”，不得推断。

等我回答后，再严格按照模板输出完整Experience Markdown，不省略栏目。
```

### 3. AI应该先做什么

先还原事实并提出问题。第一轮不是简历Bullet，也不是完整故事；AI必须拆开团队结果、个人贡献和不属于你的最终决策权。

### 4. 你确认后最终得到什么

一份单段Experience Markdown，例如`experience_01.md`，完整记录事实、交付物、Ownership、Result Scope和待确认项。
