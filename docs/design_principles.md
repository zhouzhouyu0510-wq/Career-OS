# 设计原则（Design Principles）

1. **事实优先于表达（Facts before fluency）**  
   文案更流畅，不代表可以越过Evidence。

2. **Source of Truth优先于Derived Output**  
   生成的Resume或Prepared Answer都不是Canonical Fact。

3. **Direct / Adjacent / Transferable严格区分**  
   方法相似不足以构成Direct Match，还要核对业务问题、动作、对象、产出与责任语境。

4. **Unknown也是合法输出**  
   无法确认的投递限制、岗位路径或市场信息应保留Unknown，而不是补造答案。

5. **Candidate→Job与Job→Candidate分开**  
   “我能不能胜任”和“我是否愿意接受”可以得到不同结论。

6. **Review先于Compression**  
   第一版先展示有价值的Evidence组合，再由Candidate参与最终取舍。

7. **准备答案，但不编造身份**  
   Full Reference Answer是Prepared Narrative，不会自动升级为Candidate Fact。

8. **学习按相关性迁移（Relevance-based Migration）**  
   可迁移通用问题，但不会把上一岗位的全部Gap机械复制到下一岗位。

9. **Synthetic就是Synthetic**  
   公开Demo不会通过更换名称复用私人事实。
