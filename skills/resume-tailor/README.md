# Resume Tailor｜Public Runtime Specification

Resume Tailor解决：**岗位确定以后，如何从已确认的Candidate Evidence中组合出安全、可追溯的定制简历。**

它不重新判断岗位值不值得投，也不把JD关键词写成Candidate从未拥有的能力。

Runtime先生成Content-rich Review Draft，让Candidate看见合理Evidence组合；收到反馈后再进入Submission Draft，完成删减、压缩与一页优化。
