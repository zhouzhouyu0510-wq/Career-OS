# 风险检查（Guardrails）

- 责任膨胀（Ownership Risk）
- 无证据技能（Unsupported Skill）
- 无证据结果（Unsupported Impact）
- 保密风险（Confidentiality Risk）
- 外部面经过拟合（External Anecdote Overfit Risk）
- 经历专属边界（Experience-specific Boundary）
- 背景过度包装（Background Overclaim Risk）
- 证据不可追溯（Evidence Traceability Risk）
- 关键词堆砌（Keyword Stuffing）
- 低于可读性安全线（Compression Below Readability Boundary）

External Research可以改变Evidence Priority和表达方式，但不能改变Candidate实际做过什么。
