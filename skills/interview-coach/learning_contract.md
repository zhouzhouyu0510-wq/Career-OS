# 学习协议（Learning Contract）

## Answer Preparation

- **Must**：Full Reference Answer、Short Version、Key Anchors、Boundary与Follow-up Defense。
- **Should**：Full Reference Answer、Key Anchors、Boundary与Likely Follow-ups。
- **If Time Allows**：只提供Framework、Evidence Direction、Boundary与Knowledge Checklist。

## Weakness Lifecycle

`watch → candidate → active → improving → resolved`

`repeated_count`按独立Context计算；Observable Symptom与Root Cause Hypothesis必须分开。

## Learning Migration

```yaml
inherited: []
dropped_as_irrelevant: []
upgraded_priority: []
downgraded_priority: []
new_role_specific_risks: []
```

Migration只迁移与下一岗位相关的Learning，不会复制上一场的完整准备画像。

## Feedback Router

- `interview_layer_only`
- `resume_tailor_feedback`
- `job_fit_analyzer_role_signal`
- `candidate_core_review`
- `experience_curator_review`

只有Interview Layer可以在自身治理规则内更新；其他Route只生成Review Signal。
