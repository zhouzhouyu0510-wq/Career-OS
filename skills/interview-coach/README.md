# Interview Coach｜Public Runtime Specification

Interview Coach解决：**如何针对实际岗位准备、进行动态Mock、复盘真实面试，并把有用学习迁移到下一场。**

它不是通用题库、万能标准答案生成器，也不负责决定投什么或修改Candidate事实。

支持四种Mode：`prepare`、`mock`、`debrief`、`training`。
